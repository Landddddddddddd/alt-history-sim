# 架空历史推演模拟器（Alternate History Simulator）

纯前端单文件应用（`index.html`，双击即可在浏览器打开，无需后端、无需联网服务器）。

## 它能做什么
- **自己接 Key**：填入任意 OpenAI 兼容的 API 地址 + Key，Key 只存你本机浏览器 `localStorage`，不上传任何第三方。
- **多语言**：界面与推演输出语言随切换（中文 / English / 日本語 / Español / Français）。
- **多历史节点**：可添加任意多个「分歧点」，每个节点绑定一个年份 + 事件描述；推演到达该年份时，模型**必须**触发该事件并推演连锁反应。
- **自定义推演跨度**：自由设定起始年、结束年、每步年数（例如 1200→1700，每步 50 年）。
- **尽量仿真**：维护一份世界状态 JSON（势力：GDP / 稳定度 / 军力 / 科技 / 人口 / 领导人 / 意识形态），每回合把当前状态回灌给模型，强制其保持前后连续、数值真实；每回合覆盖政治 / 经济 / 军事 / 科技 / 文化 / 外交 / 社会 多维度事件。

## 给未成年用户的特别说明（重要）
你无法实名国内 AI 平台（硅基流动 / 腾讯云 / DeepSeek / 阿里云等），也难办海外信用卡。
因此**最省事、零门槛**的方案是本地跑 **Ollama**：

1. 安装 Ollama（https://ollama.com ，Windows 一键安装，无需账号）。
2. 拉一个模型，例如 `ollama pull qwen2.5:latest`（中文友好）或 `llama3.1`。
3. 点界面上的「填入本地 Ollama」按钮，它会自动填好：
   - API 地址：`http://localhost:11434/v1`
   - 模型名：`qwen2.5:latest`
   - Key：留空
4. 直接点「开始推演」即可，**完全免费、无需任何账号/实名/Key**。

> 如果你已有合规的 OpenAI / OpenRouter 等 Key，也可以直接填进去用云端模型，效果通常更强。

## 配置字段
| 字段 | 说明 |
|---|---|
| API 地址 | OpenAI 兼容的 `/v1` 端点，如 `https://api.openai.com/v1`、`https://openrouter.ai/api/v1`、或本地 `http://localhost:11434/v1` |
| API Key | 你的密钥；本地 Ollama 留空 |
| 模型名 | 如 `gpt-4o-mini`、`qwen2.5:latest`、`llama3.1` |
| 温度 | 0=最严谨确定，越高越发散；推演建议 0.7~0.9 |
| 最大输出 token | 每回合生成上限，跨度大/势力多时调高（如 4096~8192） |
| JSON 模式 | 建议开启；让模型稳定返回结构化 JSON |

## 使用流程
1. 填好「接入模型」并点「测试连接」确认可用。
2. 在「推演方案」写标题、起止年、步长、初始世界设定（含你的 POD 假设）。
3. 在「历史节点」逐个添加分歧点（年份 + 名称 + 事件描述）。
4. 点「开始推演」。可随时「暂停 / 重置」。
5. 右侧切换「时间线 / 势力 / 原始 JSON / 运行日志」查看结果。
6. 「保存方案 / 导出 JSON / 导入 JSON / 载入示例」用于复用与分享。

## 关于 CORS（浏览器跨域）
部分云厂商 API 会拦截浏览器直连（CORS）。若出现连接失败且 Key 无误：
- 优先用 **本地 Ollama**（无 CORS 问题）；
- 或用 **OpenRouter** 等明确允许浏览器调用的服务；
- 或在本地起一个极简反向代理把请求转发给目标 API（Key 放代理环境变量，不进前端代码）。

## 提示词设计（仿真要点）
系统提示词强制模型遵守：
1. **连续性**——后续事件承接前文，数值不跳跃；
2. **多维仿真**——每回合覆盖七大维度；
3. **数值真实**——稳定/军力/科技 0-100，GDP/人口用合理量级；
4. **节点触发**——到达节点年份必须触发并推演连锁反应；
5. **只输出 JSON**——便于程序稳定解析与状态合并。

每回合的用户消息会带入：当前年份、当前完整世界状态、本回合需触发的节点列表，从而把上下文锁死，减少模型「忘前情」。

## v2 新增能力
1. **势力地图**：12 个地区（北美/南美/西欧/东欧/北非/撒哈拉以南/中东/中亚/南亚/东亚/东南亚/大洋洲）示意地图。模型每回合输出 `map` 字段（地区→势力 id），按势力配色渲染控制范围，附图例。开关在「地缘相邻 + 地图」。
2. **数值趋势图**：按年份对各族势力绘制 科技 / 稳定 / 军力 三选一的多线折线图（SVG），便于看长期消长。
3. **分支对比**：同一方案跑 2–4 遍（每遍不同随机种子），并排表格比较各年份综述与终局数值，直观看「蝴蝶效应」分歧。
4. **更强提示词**：
   - **随机事件表**：适度注入低概率但符合时代/科技的事件（瘟疫、大饥荒、地震火山、关键发明、君主暴毙、边疆叛乱、贸易改道），让走向更不可预测但合理。
   - **地缘相邻效应**：定义地区相邻关系，战争/瘟疫/贸易冲击/技术扩散沿相邻蔓延。
   - 以上两项可在「接入模型」卡片里用复选框开关，默认开启。

## v3 新增能力
1. **地图交互：点击地区看历年控制沿革**。在「地图」标签页点击任一地区，下方展开该地区的「控制沿革」：逐年条形带（颜色=控制势力，遇易主标 `⇄`）+ 表格（年份 / 势力 / 易主或维持）。再点一次或「清除选择」收起。顶部年份滑块可拖动看任意年份的势力范围，「跟随最新」按钮一键回到推演终点年。
2. **分支对比自动算「分歧起点」高亮**。除自动高亮「分歧最大年」（累积分歧度最高）外，额外计算并高亮「分歧起点年」——相对上一年分歧度增幅最大的转折年，用不同底色（橙/黄）与徽标（⚡/↯）区分，一眼看清蝴蝶效应从哪一年开始失控。分歧度列综合「势力数值差异 + 领土控制差异 + 综述文本差异」三项加权。

## 使用提示
- 分支对比会发起多倍 LLM 调用，跨度大/分支多时较耗时；建议先用本地 Ollama 跑分支。
- 地图为「示意地缘」而非精确国界，重在表现势力范围消长，不必对照真实地图。
